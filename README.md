# Subhoj Ladoos - Online Store Website

## Overview
Subhoj Ladoos is a complete e-commerce platform for ordering pure ghee ladoos, festive sweets, and Maharashtrian snacks.

## Features
- **Branding & Logo:** Features **Subhoj Ladoos** ("Made with Love, Shared with Joy")
- **Product Catalog:** Rava Ladoo, Besan Ladoo, Special Methi Ladoo, Chakali, Chivda, Modak, Puranpoli, and more with precise pricing.
- **OTP Verification:** Interactive phone verification.
- **Address & Serviceability:** Validates PIN codes for Mumbai, Thane, Palghar, Alibaug, Nashik, and Pune.
- **UPI QR Payment:** Interactive UPI QR interface with a 30-second countdown timer.
- **Notifications:** Simulated Email, SMS, and Owner WhatsApp notification dispatch to **Suresh Kumar**.

## Running Locally
1. Open `index.html` in any modern web browser.
2. For backend API: `cd backend && npm install && node server.js`
